# Product Features

Feature work for the WATM platform. Each folder contains PRDs, research, and implementation docs for a feature or initiative. Meeting notes have been consolidated into the root `Meetings/` folder.

## Structure

- **Top-level folders** = active/in-progress features
- **`COMPLETE/`** = shipped features (archived, still searchable)
