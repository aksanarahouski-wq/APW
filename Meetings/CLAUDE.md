# Meetings

All meeting transcripts and summaries for the WATM project, consolidated from across all feature folders. Covers client calls (APW), partner meetings (InHand/Orases), internal discussions, and feature-specific sessions.

## Structure

- **`Transcripts/`** — Raw meeting transcripts (50–130KB each, timestamped speaker dialogue)
- **`Summaries/`** — Condensed summaries, recaps, action items, preps, and follow-up emails (3–41KB each)

## Naming Convention

Files are prefixed by feature/context area:

| Prefix | Context |
|--------|---------|
| `2025-*` / `2026-*` | Date-named general client meetings |
| `Client_*` | General client meetings (APW) |
| `APW_InHand_Orases_*` | Partner/vendor meetings |
| `Configurations_*` | Config management system (V1 discovery) |
| `Configurations_V1_*` | Config V1 meetings |
| `Configurations_V2_*` | Config V2 redesign meetings |
| `Verizon2ndAccount_*` | Second Verizon account feature |
| `InvoicesFormatting_*` | Invoice redesign feature |
| `ServicePlanChanges_*` | Service plan enhancements (completed) |
| `ServicePlanApproval_*` | Service plan approval workflow (completed) |
| `AdminLogs_*` | Admin log improvements (completed) |
| `TMobile_DualSim_*` | T-Mobile & dual SIM management (completed) |
| `TrelloBacklog_*` | Backlog review / triage meetings |
