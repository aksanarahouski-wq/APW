## Example 1: Strategic Planning PRD

**Scenario:** Company needs to add SSO authentication to support enterprise customers

**Generated Output:** `PRD-sso-authentication-strategic.md`

```markdown
# Product Requirements Document - Enterprise SSO Authentication
## Single Sign-On (SSO) Integration

**Document Version:** 1.0
**Date:** March 1, 2026
**Author:** Product Team
**Status:** Draft
**Related Tickets:** [EPIC-123](link)
**Document Owner:** VP Product
**Last Updated:** 01.03.2026

---

## Overview

Implement enterprise-grade Single Sign-On (SSO) authentication to enable seamless integration with corporate identity providers (SAML 2.0, OIDC). This capability is critical for enterprise sales and reduces security risks by centralizing authentication.

### Key Features
- **SAML 2.0 Integration**: Support industry-standard SAML protocol for enterprise IdPs
- **OIDC Support**: OpenID Connect for modern cloud-based authentication
- **Just-In-Time Provisioning**: Auto-create user accounts on first SSO login
- **Group/Role Mapping**: Sync organizational roles from IdP to application permissions

### Business Impact
- Unlock enterprise market segment (estimated $2M ARR)
- Reduce authentication-related support tickets by 50%
- Improve security posture with centralized credential management
- Accelerate enterprise sales cycle by removing authentication blocker

---

## Background and Problem Statement

### Current State
Currently, all users authenticate via email/password stored in our application database. Enterprise customers require integration with their corporate identity providers (Okta, Azure AD, OneLogin) for:
- Centralized access control
- Compliance requirements (SOC2, ISO 27001)
- Streamlined employee onboarding/offboarding

### Problems
**Problem 1: Lost Enterprise Deals**
- Sales team reports 60% of enterprise prospects require SSO
- Lost 3 major deals (combined $1.2M ARR) in Q4 2025 due to missing SSO
- Average enterprise deal size: $200K ARR

**Problem 2: Security & Compliance Risk**
- Decentralized password management increases breach risk
- No centralized audit trail for enterprise customers
- Compliance requirements not met for regulated industries

**Problem 3: Support Overhead**
- 40% of support tickets relate to password resets and authentication
- Manual user provisioning slows enterprise onboarding
- No automated deprovisioning when employees leave customer organizations

### Impact if Not Addressed
- Miss FY2026 enterprise revenue target by $2M
- Continue losing competitive deals to competitors with SSO
- Increased security risk and potential breach liability
- Ongoing high support costs for authentication issues

---

### Primary Goals
1. **Enable Enterprise Sales**: Remove SSO as a blocker for enterprise deals
2. **Improve Security**: Centralize authentication via customer IdPs
3. **Reduce Support Load**: Eliminate password-related support tickets

- ✅ Support SAML 2.0 and OIDC protocols
- ✅ 80% of new enterprise customers adopt SSO within 90 days
- ✅ Reduce authentication-related support tickets by 50%
```

```markdown
Enable users to export their data in multiple formats (CSV, Excel, PDF) for reporting, analysis, and regulatory compliance. Users can filter, customize columns, and schedule automated exports.

- **Multi-Format Export**: CSV, Excel (.xlsx), PDF formats

- **Benefit**: One-click complete data export for compliance

**Executive** - [Link to persona]

- System opens export configuration modal

**Business Rules:**
- Export uses current page's active filters and search criteria

**Business Rules:**
- Column order in export matches selection order
- System columns (internal IDs) hidden by default
- Sensitive fields (SSN, credit cards) require additional confirmation

**FR-2.2: Data Security**
- System validates user has VIEW permission for all exported rows
- Exported data must match what user sees in UI (no hidden data)

**Business Rules:**
- Row-level security rules enforced during export
- Audit log captures exported data scope
- Exports purged from S3 after 24 hours
```

```markdown
## Overview

Add a "Copy Link" button that allows users to quickly copy shareable links to their clipboard with one click, improving the sharing experience and reducing user friction.

### Key Features
- **One-Click Copy**: Single button click copies link to clipboard
- **Visual Feedback**: Toast notification confirms successful copy
- **Keyboard Shortcut**: Cmd/Ctrl+Shift+C copies link

### Business Impact
- Reduces steps to share content from 4 (right-click URL bar → copy) to 1 (click button)
- Improves user satisfaction with sharing workflow
- Aligns with user expectations (copy buttons are standard UX pattern)

---

## Goals and Success Criteria

### Primary Goals
1. **Simplify Sharing**: Make it easier for users to share links
2. **Improve UX**: Reduce friction in sharing workflow
3. **Meet User Expectations**: Provide standard copy-to-clipboard functionality

### Success Criteria
- ✅ One-click copy works in Chrome, Firefox, Safari, Edge
- ✅ Visual feedback confirms copy success within 200ms
- ✅ Keyboard shortcut works consistently
- ✅ 90% of users successfully copy on first attempt
- ✅ No regressions in page load time

### Out of Scope
- ❌ Social media sharing buttons (future enhancement)
- ❌ QR code generation (deferred)
- ❌ Custom link shortening (deferred)

---

## Users and User Stories

### Primary Users

**All Users**
- **Need**: Quick way to share page links with colleagues
- **Pain Point**: Manual URL copying is cumbersome (select URL, right-click, copy)
- **Benefit**: One-click sharing improves workflow efficiency

### User Stories

**As any user:**
- As a user, I need to copy the current page link so that I can share it via email/chat
- As a user, I need visual confirmation the link was copied so that I know the action succeeded
- As a user, I need the copy button to work on mobile so that I can share on any device

---

## Acceptance Criteria

- [ ] "Copy Link" button visible in header/toolbar on all shareable pages
- [ ] Button click copies current page URL to clipboard
- [ ] Toast notification shows "Link copied!" for 3 seconds
- [ ] Button works in Chrome, Firefox, Safari, Edge (desktop & mobile)
- [ ] Keyboard shortcut Cmd+Shift+C (Mac) / Ctrl+Shift+C (Windows) copies link
- [ ] Button disabled if browser doesn't support Clipboard API (graceful degradation)
- [ ] Copied URL is the canonical URL (not with tracking params)
- [ ] Button has appropriate ARIA labels for accessibility
- [ ] Error toast if copy fails: "Could not copy link. Please copy manually from URL bar."

---

## Functional Requirements

### FR-1: Copy Functionality
- Button triggers navigator.clipboard.writeText() API
- Falls back to document.execCommand('copy') for older browsers
- Copies full canonical URL including domain

**Business Rules:**
- Remove tracking parameters (utm_*, ref) before copying
- Always copy HTTPS version of URL
- Copy button only visible on pages that can be shared (not on modals/dialogs)

### FR-2: User Feedback
- Success: Green toast with checkmark icon + "Link copied!"
- Error: Red toast with error icon + "Could not copy link..."
- Toast auto-dismisses after 3 seconds

---

## Technical Requirements

### Browser Support
- Chrome 66+, Firefox 63+, Safari 13.1+, Edge 79+
- Mobile: iOS Safari 13.1+, Chrome Android 66+

### Performance
- Button renders in under 50ms
- Copy action completes in under 200ms
- No impact on page load time

### Accessibility
- Button has aria-label="Copy link to clipboard"
- Toast has role="status" for screen reader announcement
- Keyboard shortcut documented and discoverable

---

## UI/UX Requirements

**Button Design:**
- Icon: Link icon with copy/duplicate indicator
- Placement: Header toolbar, right-aligned
- Label: "Copy Link" (desktop), icon only (mobile)
- Hover state: Tooltip "Copy link to clipboard"
- Active state: Pressed appearance

**Toast Design:**
- Position: Top-center, 16px from top
- Style: Matches existing toast component design
- Duration: 3 seconds
- Animation: Fade in 150ms, fade out 150ms
```

## Key Differences Between PRD Types

| Element | Strategic | Implementation | Simple |
|---------|-----------|----------------|--------|
| **Length** | 15-20 pages | 10-15 pages | 3-5 pages |
| **Detail Level** | High-level, approval-focused | Detailed, dev-ready | Essential only |
| **Background** | ✅ Full problem/solution context | ❌ Assumes approved | ❌ Brief overview |
| **User Stories** | ✅ Multiple personas | ✅ Detailed personas | ✅ Single/simplified |
| **Implementation Plan** | ✅ Phases, timeline, rollout | ❌ Omitted | ❌ Omitted |
| **Success Metrics** | ✅ KPIs, business impact | ❌ Omitted | ❌ Simple criteria |
| **TRD Likely?** | Yes (complex features) | Sometimes | Rarely |
| **Audience** | Executives, stakeholders | Engineering, QA | Engineering team |
| **Purpose** | Get approval & funding | Guide implementation | Quick specification |
